# Неделя в гифках

Разовый вечер настроения: хост открывает комнату с ноутбука, люди с телефонов выбирают две гифки, потом показ по одному человеку и общая стена.

Состояние комнаты живёт **только в памяти процесса**. Перезапуск сервера или засыпание Render Free обнуляют вечер. Базы нет.

## Что нужно заранее

1. Один или несколько ключей [GIPHY API](https://developers.giphy.com/) (тип API, не SDK).
2. Секрет хоста — любой пароль, которым вы входите на `/host`.
3. Аккаунт [Render](https://render.com/), когда будете деплоить.

Скопируйте env-файл:

```bash
cp .env.example .env
```

Заполните `HOST_SECRET` и `GIPHY_API_KEY_1` / `_2` / `_3`. Файл `.env` в git не попадает.

Ключи не отдаются всем сразу. Люди сначала только заходят по имени. Когда хост жмёт «Начать выбор», сервер **равномерно раздаёт** ключи между уже сидящими в комнате. Опоздавший получает ключ, которым пользуется меньше всего. Так три ключа дают примерно 300 поисков в час, а не 100 на всех.

Без ключей GIPHY поиск недоступен: в пикере будут несколько демо-гифок, чтобы можно было прогнать вечер локально.

## Локальный запуск

Нужен Node 20+.

```bash
npm install
npm run dev
```

- Участник: http://localhost:5173
- Хост: http://localhost:5173/host

Сервер API/сокетов слушает `0.0.0.0:3000` (или `PORT`). Vite на 5173 проксирует `/api` и `/socket.io`.

Прод-сборка как на Render:

```bash
npm run build
npm start
```

Откройте http://localhost:3000

## Как идёт вечер

1. Хост заходит на `/host`, вводит `HOST_SECRET`, жмёт «Начать вечер».
2. На экране код и QR. Ссылка вида `https://ваш-домен/j/XK4P`. QR берёт `window.location.origin`, на Render это публичный URL, не localhost.
3. Люди вводят имя и ждут. Поиск ещё закрыт.
4. Хост жмёт «Начать выбор» — ключи GIPHY раздаются поровну, на телефонах открываются два пикера.
5. Хост видит список имён и статус «ждёт» / «выбирает» / «готово», сами гифки до показа не видит.
6. «Начать показ» перемешивает тех, кто отправил. На телефонах синхронно один человек, две гифки столбиком.
7. Хост: **пробел / →** дальше, **←** назад, **S** — стена.
8. «Завершить вечер» стирает комнату.

Опоздавший во время показа всё ещё может выбрать гифки и встаёт в **конец** очереди.

## Render Free

В репозитории есть `render.yaml`: один web-сервис, без БД, без диска.

1. Запушьте репозиторий на GitHub/GitLab.
2. New Blueprint / подключите репо в Render.
3. Задайте `HOST_SECRET` и `GIPHY_API_KEY_1` / `_2` / `_3` (в blueprint они `sync: false` — значения только в Dashboard).
4. Не включайте больше одного инстанса.

Сервис слушает `0.0.0.0:$PORT`. Health-check: `GET /health`.

**Как не усыпить комнату в день ивента**

- Free засыпает примерно через 15 минут без трафика. Первый запрос после сна — холодный старт, память пустая.
- За 5–10 минут до сбора откройте сайт и вкладку `/host`. Не закрывайте её, пока идёт вечер.
- Прогоните сами дольше 15 минут: сверните все вкладки, подождите, откройте снова — комната должна пропасть. Это ожидаемо.
- Перед залом проверьте с телефона **на LTE**, не из той же Wi‑Fi, что ноут.

После вечера можно выключить сервис в Dashboard, чтобы никто не поднимал новую комнату по старой ссылке.

## Что проверить

- Хост создаёт комнату, телефон заходит по QR/коду, выбирает две гифки, хост видит «готово».
- Старт показа: на ноуте и на телефоне один человек. «Дальше» меняет слайд у обоих.
- Клавиши хоста работают.
- Стена, затем «Завершить».
- Рестарт `npm start` — комнаты нет.

## Лимит GIPHY

Beta-ключ: около 100 поисков в час. Несколько ключей раздаются по людям в момент «Начать выбор», поэтому лимиты складываются. На экране выбора обязательно стоит **Powered by GIPHY**. Поиск идёт с клиента; человек получает только свой ключ через сокет, не общий `/api/config`.
